# CrudFireBase-ReactNative

Aplicativo mobile desenvolvido em React Native com integração ao Firebase, criado para praticar operações de CRUD em uma aplicação.

## Sobre o projeto

O **CrudFireBase-ReactNative** foi desenvolvido com o objetivo de praticar cadastro, listagem, edição e exclusão de dados em uma aplicação mobile.

Durante o desenvolvimento, foram trabalhados conceitos importantes de React Native, organização de telas, manipulação de estado e integração com Firebase para persistência dos dados.

## Funcionalidades

- Cadastro de registros
- Listagem de dados
- Edição de informações
- Exclusão de registros
- Integração com Firebase
- Organização de telas e componentes
- Prática de CRUD em ambiente mobile

## Tecnologias utilizadas

- React Native
- JavaScript
- Expo
- Firebase
- Node.js / npm

## Estrutura do projeto

O projeto possui uma estrutura organizada com os arquivos principais da aplicação, incluindo:

- `assets` - arquivos e recursos visuais
- `src` - telas, componentes e arquivos da aplicação
- `App.js` - arquivo principal do app
- `package.json` - dependências e scripts do projeto

## Como executar o projeto

1. Clone este repositório:

```bash
git clone https://github.com/JohnElthon/CrudFireBase-ReactNative.git
```

2. Acesse a pasta do projeto:

```bash
cd CrudFireBase-ReactNative/FireBaseCrud-RN
```

3. Instale as dependências:

```bash
npm install
```

4. Execute o projeto:

```bash
npm start
```

5. Abra no emulador Android/iOS ou no aplicativo Expo Go.

## Observação

Projeto desenvolvido com fins acadêmicos e de aprendizado. Para utilizar corretamente as funcionalidades ligadas ao Firebase, pode ser necessário configurar as credenciais e a conexão com o projeto Firebase.
